# 🌬️ Wind Turbine Blender Project

A **3D computer animation project created with Blender**, featuring a low-poly wind turbine environment with stylized terrain and animated rotating turbine blades.

## 🎯 Project Overview

The project demonstrates fundamental **3D modeling, materials, scene organization, lighting, rendering, and animation** techniques in Blender.

The final scene contains multiple wind turbines positioned on stylized terrain, with the turbine blades animated to create a realistic rotating effect.

## 🛠️ Technologies

* **Blender**
* 3D Modeling
* Computer Animation
* Materials & Shading
* Lighting & Rendering
* Keyframe Animation

## 🔨 Main Features

* 🌱 Stylized low-poly terrain
* 🏗️ 3D wind turbine modeling
* ⚙️ Turbine mast, hub, and blades
* 🎨 Materials and low-poly shading
* 💡 Scene lighting and shadows
* 📷 Camera positioning and composition
* 🔄 Animated turbine blade rotation
* 🎬 Animation rendering

## 📐 Modeling Process

The project was developed by:

1. Creating the ground using a plane
2. Adding cylindrical platforms
3. Modeling the turbine mast, hub, and blades
4. Applying modifiers such as Bevel/Subdivision where needed
5. Organizing and aligning the turbine objects

## 🎬 Animation

The turbine blades are animated using **keyframes or drivers** to create continuous rotation.

The animation timeline and frame rate are configured in Blender before rendering.

## 🖥️ Rendering

The scene includes:

* Sun light or HDRI lighting
* Eevee/Cycles rendering
* Shadows and color adjustments
* Camera positioning
* Focal-length adjustments

## 🎥 Final Result

The final product is a **low-poly wind turbine animation showing rotating turbines on stylized terrain**.
